# Schulte Game - 舒尔特游戏

一个在线舒尔特方格训练游戏，支持多种模式。

## 在线游玩

访问：https://你的用户名.github.io/schulte-game

## 游戏模式

- **经典模式** - 5×5 方格训练
- **标准模式** - 可选 3×3 到 9×9 难度
- **唐诗模式** - 古诗词训练，带拼音显示

## 本地运行

1. 下载所有文件
2. 用浏览器打开 index.html

或启动本地服务器：

```bash
python -m http.server 8080
```

然后访问 http://localhost:8080

本项目已配置 GitHub Pages，可以直接访问在线版本。
